# Further Reading & Sources

The bootcamp is **hands-on and original**, but its concepts, vocabulary, and structure draw on the following works. Where a module uses an idea from one of these, it says so inline. We **do not reproduce** their text or figures — diagrams here are redrawn in our own style.

| Work | Authors | What we drew from it | Used in |
|---|---|---|---|
| **An Illustrated Guide to AI Agents** | Maarten Grootendorst (O'Reilly) | The "augmented-LLM = agent" spine; memory taxonomy; **context engineering**; tool lifecycle; MCP framing | M0, M1, M5, M6, GLOSSARY |
| **AI Agents: The Illustrated Guidebook (2025)** | Avi Chawla & Akshay Pachaar (Daily Dose of DS) | 6 building blocks; the **5 core patterns**; the **5 Levels** ladder; project ideas | M1, PATTERNS.md |
| **Agentic Design Patterns** | Antonio Gullí | The **21-pattern catalog** and its organization | PATTERNS.md, module cards |
| **Mastering AI Agents** | Pratik Bhavsar (Galileo) | Agent **evaluation metrics taxonomy** and **failure-modes → fixes** | M10 |
| **Agents** (whitepaper) | Google | Model/Tools/Orchestration triad; **Extensions / Functions / Data Stores** tool taxonomy | M1, M5 |
| **Introduction to Agents** | Google | The **Level 0–4** agency taxonomy; AgentOps; agent security | M1 (ladder) |
| **Building Applications with AI Agents** | Michael Albada (O'Reilly) | Multi-agent architecture; agent UX design | M2, M7–M8 *(planned)* |
| **Agentic Mesh** | Eric & Davis Broda (O'Reilly) | Enterprise agent ecosystem & governance | Enterprise/Capstone *(planned)* |
| **AI Agents in Action** | Michael Lanham (Manning) | Hands-on exercise inspiration | Labs *(planned)* |

> Learners who want to go deeper are encouraged to read the originals. Nothing in this repository replaces them; it condenses and applies their ideas for instructor-led delivery.
