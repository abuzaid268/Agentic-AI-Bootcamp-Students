## Session Calendar

Each session is a **4-hour block**. Five-hour modules are split at natural concept/lab breaks (marked *Part 1* / *M▸M*) so nothing overruns. Content spreads across **~11 weeks** with two break weekends so the program breathes. **Phases 1–6 (M1–M12, incl. M5B Agent Skills)** build agents from scratch; **Phase 7 (M13–M15)** rebuilds them on **Microsoft Foundry** — the managed cloud twin.

## Assessment Weighting

| Component | Weight |
|:--|:--:|
| Capstone project | 30% |
| Mini-projects (6 — incl. Cloud mini-project) | 35% |
| Practical evaluations (2) | 15% |
| Phase quizzes (7) | 10% |
| Participation & lab completion | 10% |

> **Pass bar:** ≥ 70% overall **AND** a working capstone meeting all mandatory requirements.

## Attendance

A full **attendance register** (20 participants × 19 sessions) is maintained by the training team, with a per-learner *Present /19* count. Mark **P** = present, **A** = absent.
