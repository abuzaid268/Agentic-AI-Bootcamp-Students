Program at a glance

Designed for graduate students and working engineers with basic Python. Framework-agnostic principles first, then implementation — every module ends with a working artifact, not a slide. Pedagogy: Build → Test → Improve.

AudienceGraduate students & engineers with basic Python proficiency
FormatInstructor-led workshop · cohort of ~20 learners
Core stackPython · LangGraph · CrewAI · MCP · A2A · Microsoft Foundry · GitHub Copilot
OutcomeJob-ready: design, build, evaluate, and deploy agentic AI systems — self-hosted and on the cloud (Microsoft Foundry)
Each module shipsLearner Handout · Lab Worksheet · starter + solution code (Phase 7: branded notebooks + weekly mini-projects)

What you'll be able to do

Tell a single LLM call apart from a workflow and a true autonomous agent — and build each.

Implement ReAct, planning, and reflection patterns with structured, parse-safe outputs.

Connect agents to live tools through the Model Context Protocol (MCP).

Give agents persistent long-term memory that survives restarts and cites sources.

Orchestrate multi-agent crews and let frameworks interoperate via A2A.

Evaluate, trace, guard-rail, and deploy agents under real cost and latency budgets.

Rebuild agents on the managed cloud — Microsoft Foundry Agent Service, grounding, content safety, and evaluation.

Curriculum · 7 phases

PHASE 1

Foundations & Mental Models

From “what is an LLM” and “what is an agent” to a reproducible engineering setup and a framework-agnostic mental model.

9hM0–M2
M0

LLM & Reasoning Primer

~1h

Pre-work primer: understand the LLM you're about to augment — a token-in/token-out function, its context window, temperature, and parametric memory — and why reasoning LLMs (“thinking tokens”) improve planning and tool selection. Hands-on micro-lab feels statelessness, temperature, and reasoning vs plain models.

Deliverable LLM/reasoning notes + micro-labConcept / Lab: 0.7 / 0.3h
M1

What Agentic AI Really Is

4h

Build a bare-metal agent loop in pure Python (no frameworks) and a one-page “Is this an agent?” decision note. Distinguish a single LLM call vs a workflow vs an autonomous agent, and run the perceive → reason → act → observe loop with a step budget and cost counter.

Deliverable Bare-metal agent loop + decision noteConcept / Lab: 1.5 / 2.0h
M2

Architectures & the 2026 Stack

4h

Stand up a reproducible repo scaffold (venv, lockfile, git-ignored secrets) and the same “hello agent” in both LangGraph and CrewAI. Draw the agentic reference architecture and correctly place MCP (agent ↔ tools) vs A2A (agent ↔ agent).

Deliverable Repo scaffold + dual-framework hello agentConcept / Lab: 2.0 / 1.5h
